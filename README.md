# Lab 10 - Pay Calculator

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

To run your code open `index.html` and then click on the *Go Live* button in the bottom right.  This will open a browser page, and should refresh every time your work saves.

`sketch.js` already has starter code. Complete the following:

1. Complete the function `calculateNetPay()` so it **returns** the pay of an employee, given their **wage** and **hours** worked.

   - If they work more than 40 hours, they earn **double** their wage on the **additional** hours.

   - For example, someone who works 45 hours earns their regular wage for 40 hours, and double wage for 5 hours.

2. Use the function **again** to calculate the pay for a second employee (you decide the values, or use an input box).
